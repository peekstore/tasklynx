# Support

Thank you for using Tasklynx! We're here to help you get the most out of your local task manager.

## Documentation

Before opening an issue or asking for support, please consult the project documentation:
- **Getting Started Guide**: [docs/getting-started.md](docs/getting-started.md)
- **CLI Reference**: [docs/cli.md](docs/cli.md)
- **Configuration**: [docs/configuration.md](docs/configuration.md)
- **FAQ**: [docs/faq.md](docs/faq.md)
- **Troubleshooting**: [docs/troubleshooting.md](docs/troubleshooting.md)

## Asking Questions

If you have questions about how to use Tasklynx:
- Open a discussion on GitHub: [GitHub Discussions](https://github.com/peekstore/tasklynx/discussions)
- Check previously answered questions in issues and discussions.

## Reporting Bugs & Requesting Features

- **Bug Reports**: Please open an issue using the [Bug Report template](https://github.com/peekstore/tasklynx/issues/new?template=bug_report.md). Include your OS version, Tasklynx version (`tx --version`), and reproduction steps.
- **Feature Requests**: Submit ideas via the [Feature Request template](https://github.com/peekstore/tasklynx/issues/new?template=feature_request.md).
