# FAQ

**Q: Is data stored locally?**  
A: Yes, all tasks in local JSON, no remote sync.

**Q: What is the alias?**  
A: Use `tx` as shorthand for `tasklynx`.

**Q: Can I use on multiple machines?**  
A: Copy the tasks.json file manually.

**Q: How to update?**  
A: Run `tx self update`.
