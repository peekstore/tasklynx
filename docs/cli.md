# CLI reference

| Command | Purpose |
|---|---|
| `add` | Create a task |
| `list` | Filter tasks |
| `complete` | Complete a task |
| `doing` | Move to doing |
| `reopen` | Reopen a task |
| `edit` | Modify a task |
| `duplicate` | Clone a task |
| `search` | Search tasks |
| `today` | Show due/overdue work |
| `stats` | Show project statistics |
| `branch` | Manage task branches |
| `export` | Export JSON/Markdown |
| `web` | Start dashboard |
