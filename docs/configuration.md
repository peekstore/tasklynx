# Configuration

Configuration lives at `~/.config/tasklynx/config.toml` on Linux/macOS. The web UI uses the same terminal-inspired palette.

```toml
accent = "#ff453a"
background = "#070809"
panel = "#101216"
foreground = "#f5f5f5"
muted = "#8f949e"
font_family = "ui-monospace, SFMono-Regular, Menlo, Consolas, monospace"
```
